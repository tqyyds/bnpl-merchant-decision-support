# BNPL 商户决策支持系统

由 **[tqyyds](https://github.com/tqyyds)** 独立完成的应用数据科学项目，覆盖数据清洗、特征工程、时序建模、商户组合优化与交互仪表盘。

[English README](README.md) · [结果与证据](docs/RESULTS.md) · [系统架构](docs/ARCHITECTURE.md)

## 项目目标

利用商户历史交易，为 BNPL 平台生成最多 100 家商户的可解释候选组合，同时提供五个业务分组的独立 Top-10 推荐。将收入预测、历史准入规则、置信度和集中度诊断整合为可以核查与讨论的决策产品。

## 主要成果

- 清洗 **14,195,505 笔交易、499,999 名消费者、4,422 条商户主表记录**，实现版本化 ETL、不可变原始输入、关联检查与 SHA-256 溯源。
- 构建 **90 天历史 / 28 天预测**的滚动特征，使用 6 个训练、3 个验证和 8 个测试时间截点，避免未来信息进入训练。
- 比较收入基线、Ridge、梯度提升与三随机种子的因果 TCN；依据固定晋级规则保留 90 天基线，其历史验证集平均 **NDCG@100 为 0.993859**。
- 使用 SciPy 二元混合整数优化生成商户组合，并提供容量、类别集中度和低置信度约束的敏感性方案。
- 开发交互仪表盘，支持商户筛选、证据查看、置信度诊断、历史方案比较与来源完整性检查。

以上模型指标来自保留的历史验证结果，不代表线上业绩或真实利润。TCN 已实际训练，但未通过替代基线的预设规则。

## 本地演示

可直接打开 **[在线合成数据演示](https://tqyyds.github.io/bnpl-merchant-decision-support/)**，或在本地运行：

```bash
git clone https://github.com/tqyyds/bnpl-merchant-decision-support.git
cd bnpl-merchant-decision-support
python -m http.server 8767 --bind 127.0.0.1 --directory dashboard
```

打开 [http://127.0.0.1:8767/?demo=1](http://127.0.0.1:8767/?demo=1)。演示仅使用虚构商户与合成数值，无需课程数据或模型。完整复现需要单独获得授权的原始数据，说明见 [REPRODUCING.md](docs/REPRODUCING.md)。

## 作者与公开范围

个人仓库维护者与项目作者为 tqyyds。项目源于 MAST30034 BNPL 课程场景，此前存放于小组命名仓库；本公开版保留代码来源与校验记录。课程原始数据、消费者与交易明细、真实商户推荐名单、模型文件及笔记本执行输出均不公开。

系统预测的是手续费收入代理值；风险证据不等于经过验证的预期损失，部分区间校准不足，最新预测缺少未来真实结果。详细边界见 [RESULTS.md](docs/RESULTS.md)。
